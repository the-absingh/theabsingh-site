# Design references kept for later

## Dark tabbed systems section (premium visual v2)

The discarded intermediate concept used a full-width near-black section with a blue ambient glow, a large left-aligned heading, and five horizontal capability tabs. Selecting a tab revealed a bordered two-column panel: positioning and a large metric on the left, an animated four-step “Live System Trace” on the right. The user especially liked the third/Vision tab and may want this treatment restored later as a compact case-study section.

Do not restore it to the current product-showroom build unless requested. If restored, use it below the three core interactive chapters as an assorted case-study navigator—not as the primary capabilities presentation.
